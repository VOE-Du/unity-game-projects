# Unity 2D & 3D Game Projects

A portfolio repository containing two Unity game projects: a 2D action game and a first-person 3D escape-room puzzle game.

## 1. Dungeon Crossfire — 2D Action Game

A 2D pixel-style action game developed in Unity.

### Highlights

- Two playable levels with increasing difficulty
- Player movement, dashing, melee and ranged combat
- Multiple enemy types with different combat behaviours
- Finite State Machine (FSM) enemy logic
- Line-of-sight detection
- A* pathfinding for advanced enemies
- Item drops for health and energy recovery
- Persistent leaderboard and settings
- Pause, victory, failure, and settings interfaces

## 2. Before I Wake — 3D Escape Room

A first-person 3D escape-room puzzle game set in a dark school environment.

### Highlights

- Four connected puzzle rooms
- Environmental storytelling and light-horror atmosphere
- First-person exploration and object interaction
- UV-light, classification, chemistry, and password puzzles
- Progressive hints and UI feedback
- Puzzle-state and interaction management
- Playtesting and difficulty evaluation
- Complete escape-room gameplay loop
